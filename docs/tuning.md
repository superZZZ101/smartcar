# 调参指南

调参全部在车上用三个按键完成，改完立即写 W25Q64，掉电不丢。
顺序建议：**方向 → 速度环 → 转向环 → 存档**。

## 0. 准备

- 已烧固件，且已用 `tools/send_font.bat COM4` 烧过字库（否则菜单是空白）。
- 车轮架空时先确认方向：进 `pwm` 菜单，`step:±100` 切到 `+`，按 `L`，
  左轮应向前转；右轮同理。方向反了先改接线，别用软件硬掰。

## 1. 速度环（`spdPI` 菜单）

速度环的目标是“给定目标轮速，编码器在 10 ms 内跟上”，与赛道无关，可架空调。

1. 进 `PI tune`，`ENTER` 在 L / R / 退出之间切换，`UP/DOWN` 给目标值（±50 一档）。
2. 先只给 P（`Si` 置 0），把 `Sp` 从 0 加到车轮能快速响应但不振荡。
3. 再加 `Si`，消掉稳态误差。积分限幅在代码里是 ±1e5，一般用不到。
4. 两轮分别看一遍，目标值与实际值差距稳定在个位数即可。

常用步长：`±0.005 / ±0.02 / ±0.1 / ±1.0`（`step` 项循环切换）。
小步长用于收尾，别在粗调阶段用 ±0.005 磨。

## 2. 转向环（`PID` 菜单）

转向环调的是“线位置偏差 → 差速量”。必须在赛道上调，且速度环已经调好。

1. `BASE_SPEED` 先从 250 起（宏在 `line_following.h`），确认能稳定跑直线。
2. 先把 `I`、`D` 清零，只加 `P`：从小到大加到开始小幅画龙，再回退一档。
3. 加 `D` 抑制画龙。本车 D 项带 0.6/0.4 低通，D 可以给得比常规大一些。
4. 最后给很小的 `I` 消直道偏移；`I` 过大会在入弯时过冲。
5. 入弯冲出去：降 `BASE_SPEED` 或加大 `D`；直道高频抖：降 `D` 或降 `P`。

常用步长：`±0.0025 / ±0.02 / ±0.1 / ±1.0`。

## 3. 一组实测可用参数

某一版车体（轮距 135 mm、11 mm 灰度间距）在调参记录里留下的值：

| 参数 | 值 | 含义 |
| --- | --- | --- |
| `kp` | 6.0 | 转向 P |
| `ki` | 0.0025 | 转向 I |
| `kd` | 3.0 | 转向 D |
| `kp_spd` | 0.32 | 速度环 P |
| `ki_spd` | 0.07 | 速度环 I |

仅作起点参考：换电机、换轮径、改 `CTRL_INTERVAL_MS` 都要重新标定。
`CTRL_INTERVAL_MS` 从 10 ms 改成别的值时，`ki`/`ki_spd` 要按比例缩放，
否则积分作用强度会变。

## 4. A/B 双版本槽

`ver` 菜单提供 `save A / save B / load A / load B`：

1. 调出一组能跑完的参数，`save A`。
2. 继续尝试更激进的参数，`save B`。
3. 比赛/测试时用 `load A` 与 `load B` 快速切换对比，不用重新手调。

两槽都在 W25Q64，与当前参数（`0x050000`）互不覆盖。

## 5. 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 菜单空白，只有英文/数字 | 未烧字库，或字库 CRC 校验失败 | 重跑 `send_font.bat COMx`，换低波特率再试 |
| 上车就往一边冲 | 灰度极性反了 | 改 `bsp_IR_io.c` 的 `GRAY_ACTIVE_LEVEL` |
| 压黑线时读数不变 | 地址线接错/未设为输出 | 对照 `docs/hardware.md` 检查 AD0~AD2 |
| 编码器速度恒为 0 | A 相没接中断脚，或 B 相没接 | 检查 PA0/PA1、PA8/PA9 |
| 编码器速度符号相反 | 左右电机镜像 | 在 `Encode.c` 里交换对应 `++/--` |
| 直道画龙 | `kp` 过大或 `kd` 过小 | 按上面第 2 步回退一档 |
| 丢线后原地打转不停 | 找不到线且 2 s 超时未触发 | 检查 `lost_line_flag` 菜单项是否为 1 |
| 改参数后行为没变 | 改的是速度环却去看转向 | `PID` 与 `spdPI` 是两套独立参数 |

## 6. 调试打印

`line_following.c` 里有 `#ifdef PID_DEBUG` 的串口打印（位置/误差/P/I/D/输出/传感器字节）。
在 Keil 的 C/C++ 预定义宏里加上 `PID_DEBUG`，并把 `printf` 重定向到 UART0，
即可在 115200 串口助手里看到每周期数据。
